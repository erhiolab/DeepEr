# 发布更新流程

## 概述

DeepEr 使用 Tauri v2 的 `tauri-plugin-updater` 实现应用自动更新. 
更新源为 GitHub Releases, 每次发版后应用内的"检查更新"功能会自动发现新版本. 

## 自动更新流程

![更新流程](https://img.shields.io/badge/自动更新-enabled-green)

1. **用户点击 "检查更新"** → 前端调用 `@tauri-apps/plugin-updater` 的 `check()` API
2. **发现新版本** → 自动调用 `downloadAndInstall()` 下载并安装
3. **更新完成** → 提示用户重启应用生效
4. **更新失败** → 自动降级为"手动更新", 跳转 GitHub Releases 页面

## 签名密钥

Tauri 的 updater 使用 **minisign** 签名算法对更新包签名. 需要在构建时配置:
- **公钥**: 存放在 `tauri.conf.json` 的 `plugins.updater.pubkey` 中(可安全提交到仓库)
- **私钥**: 保存在本地 `.tauri-keys/deeper.key`(已加入 `.gitignore`, 禁止提交)

### 首次初始化

```bash
# 在 app/desktop 目录下
pnpm tauri signer generate -w .tauri-keys/deeper.key -p "<你的密码>"
```

该命令会生成两个文件:
- `.tauri-keys/deeper.key` _ **私钥**, 绝不可泄露或提交
- `.tauri-keys/deeper.key.pub` _ 公钥, 内容配置到 `tauri.conf.json`

**警告**: 私钥丢失后将无法再向已有用户推送自动更新! 请安全备份.

## GitHub Secrets 配置

在仓库 **Settings → Secrets and variables → Actions** 中添加:

| Secret | 值 |
| ------ | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | 完整私钥内容 (`.tauri-keys/deeper.key` 文件内容) |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | 私钥密码 (生成时设置的密码) |

> 私钥内容可以直接粘贴, 也可以使用单行 base64 格式, workflow 会自动处理.

## 发版命令

每次发布新版时:

```bash
# 1. 更新版本号 (三处保持一致)
#   - app/desktop/package.json        → "version"
#   - app/desktop/src-tauri/Cargo.toml → [package].version
#   - app/desktop/src-tauri/tauri.conf.json → "version"

# 2. 提交并打 tag
git add -A
git commit -m "Release v0.2.0"
git tag v0.2.0
git push origin main --tags
```

推送 `v*` tag 后, GitHub Actions (`release.yml`) 会自动:
1. 构建前端 (`pnpm build`)
2. 构建 Tauri 应用 (带签名)
3. 生成 `latest.json` 更新清单
4. 创建 GitHub Release, 上传:
   - 安装包 (`*.exe`, `*.msi`)
   - 更新包 (`*.zip`, `*.sig`)
   - `latest.json` 清单

## 更新源地址

`tauri.conf.json` 中的 `plugins.updater.endpoints` 配置为:

```
https://github.com/erhiolab/DeepEr/releases/latest/download/latest.json
```

确保每次发布时 `latest.json` 作为 release asset 上传. 

## 本地验证签名构建

```bash
# Windows PowerShell
# bundle/build 命令只认 TAURI_SIGNING_PRIVATE_KEY (可接受私钥内容或私钥文件路径)
$env:TAURI_SIGNING_PRIVATE_KEY = ".tauri-keys/deeper.key"   # 私钥文件路径
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "<你的密码>"

cd app/desktop
pnpm tauri:build
```

成功后 `src-tauri/target/release/bundle/` 下会生成带 `.sig` 签名的更新包.
