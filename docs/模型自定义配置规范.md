# 模型自定义配置规范

## V1.0.0 规范设计

```jsonc
{
  // 配置结构版本, 不兼容变更时 +1 用于迁移
  "version": 1,
  // 模型名称 (显示用, 用于模型列表等界面展示)
  // 缺失或为空时, 界面回落显示模型目录名 (id); 可随时修改
  "name": "名字",
  // 模型展示图标 (相对模型目录的图片路径, 任意支持的图片格式, 如 gif/png/webp 等)
  // 用于模型列表卡片封面展示; 缺失或加载失败时前端回落默认图标
  "image": "",
  // 渲染配置
  "render": {
    // 模型缩放比例, 1 为原始大小
    "scale": 1.0,
    // X 轴偏移, 范围 -2 ~ 2
    "posX": 0.0,
    // Y 轴偏移, 范围 -2 ~ 2
    "posY": 0.0,
    // 模型整体旋转角度 (度), 范围 0 ~ 360
    // 0 为原始朝向; 以模型画布中心为轴旋转整个视图, 90/180/270 为直角朝向
    // >180° 时自动水平镜像, 避免模型左右颠倒 (如鼠标在左而模型却看向右)
    "rotation": 0
  },
  // 显示质量 (渲染倍率), 范围 0.25 ~ 1.0
  // 1.0 为原始输出分辨率 (跟随设备像素比)
  // 值越低渲染分辨率越低, 越节省 GPU/内存, 画面会相应变模糊
  // 低性能设备可调低该值以避免卡顿
  "quality": 1.0,
  // 用户自定义可触摸区域数组
  "touches": [
    {
      // 唯一 id, 生成后不变, 用于增删改
      "id": "t-7f3a2c",
      // 用户命名, 用于显示与回调
      "name": "头",
      // 触摸类型: tap=点击 / swipe=磨蹭(来回滑动)
      "type": "tap",
      // 归一化坐标 0~1, 相对模型画布宽高, 与 l2d getHitAreaBounds() 一致
      "x": 0.35,
      "y": 0.10,
      // 归一化宽高 0~1
      "w": 0.30,
      "h": 0.25,
      // 可选: 该区域展示/图标图片地址
      "image": "",
      // 可选: 触发回调时携带的描述, 供 AI 理解
      "prompt": "用户摸了头"
    }
  ]
}
```
