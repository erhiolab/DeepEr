# 窗口权限

|                     权限                     |              说明              |
| :------------------------------------------: | :----------------------------: |
|           `core:window:allow-show`           |          允许显示窗口          |
|           `core:window:allow-hide`           |          允许隐藏窗口          |
|        `core:window:allow-set-focus`         |       允许让窗口获取焦点       |
|      `core:window:allow-start-dragging`      |        允许前端拖动窗口        |
|    `core:window:allow-set-always-on-top`     |    允许设置窗口是否始终置顶    |
|         `core:window:allow-set-size`         |      允许动态设置窗口大小      |
|      `core:window:allow-set-resizable`       |   允许设置窗口是否可调整大小   |
|  `core:window:allow-start-resize-dragging`   | 允许前端调整窗口大小(对角方向) |
| `core:window:allow-set-ignore-cursor-events` |  允许设置窗口是否忽略鼠标事件  |
|       `core:window:allow-set-position`       |      允许动态设置窗口位置      |
|     `core:window:allow-set-decorations`      |  允许动态设置窗口边框/标题栏   |
|     `core:window:allow-set-skip-taskbar`     |  允许设置窗口是否显示在任务栏  |
|               `opener:default`               |        允许打开外部链接        |
|          `core:window:allow-close`           |          允许关闭窗口          |
|          `core:event:allow-listen`           |          允许监听事件          |
|             `core:event:default`             |          允许触发事件          |
|               `dialog:default`               |         允许打开对话框         |
|        `core:window:allow-outer-size`        |    允许动态设置窗口外部大小    |
|            `core:window:default`             |        允许默认窗口操作        |
|          `core:window:allow-center`          |        允许窗口居中显示        |
|              `updater:default`               |          允许更新窗口          |
|              `process:default`               |          允许操作进程          |
